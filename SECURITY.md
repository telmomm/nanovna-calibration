# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it privately through [GitHub security advisories](https://github.com/telmomm/nanovna-calibration/security/advisories/new).

Include the affected file or workflow, the environment, reproduction steps, and any relevant logs. Do not include credentials, private measurement data, or other sensitive information.

## Scope

This project is primarily a scientific analysis workflow. Security reports may concern Python code, notebooks, GitHub Actions, dependency configuration, or accidental exposure of credentials and private data.
