# `rfmeasurement` Dependency

This project uses `rfmeasurement` as a context, validation, and reproducibility layer on top of `scikit-rf`.

Referencia:

> Miguel-Medina, T. (2026). *rfmeasurement: an open-source framework for uncertainty-aware validation and reproducible analysis of RF measurements*. Version 0.1.0. https://doi.org/10.5281/zenodo.22058515

Repositorio: <https://github.com/telmomm/rfmeasurement>

The public API is pre-1.0 and may change. The local SOL calibration remains separate because the Touchstone adapter and instrument calibration are not yet part of its public API.
